# 🌍 İklim Değişikliği Bilgilendirme Projesi

Bu proje, **iklim değişikliği hakkında insanları bilgilendirmek** amacıyla hazırlanmış basit bir web sitesidir.

## 📌 Proje Hakkında

Web sitesinde iklim değişikliğinin ne olduğu, nedenleri ve bu konuda insanların neler yapabileceği hakkında bilgiler bulunmaktadır.

Proje, özellikle web geliştirmeye yeni başlayan kişilerin anlayabileceği **basit ve sade bir yapıda** hazırlanmıştır.

## ✨ Özellikler

* 🌱 İklim değişikliği hakkında bilgilendirme
* 💡 İklim değişikliğiyle mücadele için öneriler
* ❓ Kullanıcıların merak edebileceği sorulara cevaplar
* 🔘 Sayfalar arasında geçiş sağlayan butonlar
* 🎨 Basit ve kullanıcı dostu arayüz

## 🛠️ Kullanılan Teknolojiler

* **Python**
* **Flask**
* **HTML**
* **CSS**

## 🚀 Projeyi Çalıştırma

Öncelikle gerekli kütüphaneyi yükleyin:

```bash
pip install flask
```

Daha sonra Python dosyasını çalıştırın:

```bash
python mezuniyet.py
```

Tarayıcıdan `127.0.0.1` adresine girerek web sitesini açabilirsiniz.

## 🎯 Projenin Amacı

Bu projenin amacı, **iklim değişikliği konusunda temel bilgiler vermek ve insanların çevreye karşı daha bilinçli davranmasına yardımcı olmaktır.**

## 📚 Öğrenme Amacı

Bu proje hazırlanırken Flask ile web sitesi oluşturma, HTML ile sayfa tasarlama, CSS ile arayüz geliştirme ve farklı sayfalar arasında bağlantı oluşturma gibi temel web geliştirme konuları öğrenilmiştir.
